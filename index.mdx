POMWright is a TypeScript companion framework for Playwright that formalizes the Page Object Model with a typed locator registry, automatic chain resolution, session storage helpers, structured logging, and a `@step()` decorator — all of which can be adopted independently or together.

## Why POMWright?

Playwright's best practices emphasize locator chaining for robustness. In practice, manually writing and maintaining those chains across large test suites becomes tedious and error-prone. POMWright's solution is the `LocatorRegistry`, which builds full locator chains automatically from single, typed path definitions.

## Get Started

<Steps>
  <Step title="Install POMWright">
    Add POMWright as a dev dependency alongside `@playwright/test`.

    ```bash
    pnpm add -D pomwright
    ```
  </Step>
  <Step title="Create a PageObject">
    Extend `PageObject`, define your locator paths, and implement `defineLocators()`.

    ```ts login.page.ts
    import { type Page } from "@playwright/test";
    import { PageObject, step } from "pomwright";

    type Paths =
      | "main"
      | "main.form@login"
      | "main.form@login.input@username"
      | "main.form@login.input@password"
      | "main.button@login";

    export class LoginPage extends PageObject<Paths> {
      constructor(page: Page) {
        super(page, "https://example.com", "/login");
      }

      protected defineLocators(): void {
        this.add("main").locator("main");
        this.add("main.form@login").getByRole("form", { name: "Login" });
        this.add("main.form@login.input@username").getByLabel("Username");
        this.add("main.form@login.input@password").getByLabel("Password");
        this.add("main.button@login").getByRole("button", { name: "Login" });
      }

      protected pageActionsToPerformAfterNavigation() {
        return [
          async () => {
            await this.getNestedLocator("main.form@login").waitFor({ state: "visible" });
          },
        ];
      }

      @step()
      async login(username: string, password: string) {
        await this.getNestedLocator("main.form@login.input@username").fill(username);
        await this.getNestedLocator("main.form@login.input@password").fill(password);
        await this.getNestedLocator("main.button@login").click();
      }
    }
    ```
  </Step>
  <Step title="Wire a Playwright fixture">
    Extend Playwright's `test` with your page objects as fixtures.

    ```ts fixtures.ts
    import { test as base } from "@playwright/test";
    import { LoginPage } from "./login.page";

    type Fixtures = { loginPage: LoginPage };

    export const test = base.extend<Fixtures>({
      loginPage: async ({ page }, use) => {
        await use(new LoginPage(page));
      },
    });
    ```
  </Step>
  <Step title="Write your test">
    Use the fixture in a test — navigation, chained locators, and step reporting are all automatic.

    ```ts login.spec.ts
    import { test } from "./fixtures";

    test("login flow", async ({ loginPage }) => {
      await loginPage.navigation.gotoThisPage();
      await loginPage.login("alice", "secret");
    });
    ```
  </Step>
</Steps>

<Tip>
  POMWright's helpers — locator registry, session storage, logging, and the step decorator — can each be adopted independently. Start with just the `LocatorRegistry` if you prefer a functional approach without a base class.
</Tip>
